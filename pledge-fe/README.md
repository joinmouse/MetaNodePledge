# Market Pool

Market Pool 是固定利率借贷市场，连接出借方和借款方。

## 核心功能

- **出借方（Lender）**：提供稳定币（BUSD/USDT/PLGR），锁定固定利率收益
- **借款方（Borrower）**：抵押加密资产（BTCB/ETH等），借出稳定币使用

## 池子分类

- **BUSD池**：主流稳定币借贷池
- **USDT池**：预留功能（即将上线）
- **PLGR池**：协议代币池，提供更高收益激励

## 关键参数

- **Fixed Rate**：固定年化利率
- **Margin Ratio**：清算阈值，控制风险
- **Settlement Date**：结算时间
- **Length**：借贷周期
- **Interest**：利息
- **Liquidation Price**：清算价格
- **Liquidation Ratio**：清算阈值

| 配置项 | 值 |
|--------|-----|
| 网络名称 | BSC Testnet |
| RPC URL | `https://bsc-testnet-rpc.publicnode.com` |
| Chain ID | `97` |
| 符号 | BNB |
| 区块浏览器 | `https://testnet.bscscan.com` |

#### ✅ 第三步：获取测试代币

- 访问 [BSC Testnet Faucet](https://www.bnbchain.org/en/testnet-faucet) 获取测试 BNB

### 测试模块四：异常场景测试

| 序号 | 测试点 | 操作步骤 | 预期结果 |
|------|--------|----------|----------|
| 4.1 | 余额不足 | 输入超过余额的金额 | 按钮变灰，提示 Insufficient Balance |
| 4.2 | 流动性不足 | Swap 大额代币 | 提示 Insufficient liquidity |

| 4.5 | 交易拒绝 | MetaMask 中拒绝交易 | 提示用户已拒绝 |
